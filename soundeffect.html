Pixel League 音效系统交付框架

这是一个面向代码交付的音效设计骨架，服务于当前战斗反馈与后续技能、环境和 UI 音效扩展。

交付目标

  • 以工程化方式组织音效模块，便于持续扩展。
  • 让攻击命中、击杀反馈接入战斗核心，而不是散落在视觉脚本中。
  • 保持低成本、零资源包、无复杂依赖的实现方式。

当前已落地

  • SFX.playAttackHit()：命中时播放短促音效
  • SFX.playKill()：单位死亡时播放击杀反馈
  • 支持按距离做立体声 pan 处理
  • 支持按伤害类型切换音色参数

代码组织结构

js/
├─ sound.js：音效系统入口与通用生成器
├─ combat.js：伤害和死亡事件发射点
├─ hero_*.js：技能释放事件，可在这里扩展 cast/hit 音效
└─ main.js / ui.js：界面和菜单触发音效入口

职责拆分

模块职责要求
sound.js 创建 AudioContext, 生成音色, 组织事件注册 必须只负责音频实现，不处理逻辑判断
combat.js 在伤害事件、击杀事件上发出 SFX 请求 触发必须发生在真实战斗结果之后
hero_*.js 技能施放、命中、受击等音频参数定制 每个英雄可覆写一套技能音色策略

核心接口框架

class SoundSystem {
  constructor() {
    this.ctx = null;
    this.enabled = true;
    this.registry = new Map();
  }

  init() {}
  ensureContext() {}
  register(name, fn) {}
  play(name, payload = {}) {}

  playTone({ freq, duration, gain, type, slide, pan }) {}
  playNoise({ duration, gain, color, pan }) {}

  playAttackHit(src, tgt, type, amt) {}
  playKill(unit, src) {}
}

const SFX = new SoundSystem();

事件命名约定

  • attackHit：普通命中 / 受击反馈
  • kill：单位死亡
  • skillCast：放技能
  • skillHit：技能命中
  • heal：治疗/恢复
  • pickup：拾取奖励
  • uiClick：界面点击

调用流程

// 1. 战斗核心判定真正造成伤害
if (t.hp <= 0) killUnit(t, src);

// 2. 伤害和死亡事件由核心统一触发
SFX.playAttackHit(src, t, type, amt);
SFX.playKill(u, src);

// 3. 可扩展音效事件注册
SFX.register('skillCast', ({ hero, skillName }) => {
  // 生成对应技能音型
});

设计原则

  • 事件不直接写在渲染层，避免重复触发和混乱管理
  • 音频参数只在音效层决策，战斗层只负责“发生了什么”
  • 每一种伤害类型、每一种单位层级都可以在音效层细分

当前已实现的参数策略

事件参数当前策略
attackHit type / amt / pan 物理音色偏硬，魔法偏亮，真伤偏尖锐
kill boss / elite / unit 普通敌人短促，boss 增加低频冲击和尾音

扩展路线

// 技能音效扩展示例
SFX.register('skillCast', ({ hero, skillName }) => {
  if (hero.id === 'fortune') {
    SFX.playTone({ freq: 420, duration: 0.12, gain: 0.08, type: 'triangle', pan: 0 });
  }
});

SFX.register('heal', ({ amount }) => {
  SFX.playTone({ freq: 660, duration: 0.14, gain: 0.05, type: 'sine', slide: 80, pan: 0 });
});

后续迭代计划

  • 加入 技能释放音：每个英雄做到独立克制音效

  • 加入 治疗 / 奖励 / 升级：强化正反馈节奏
  • 加入 boss 特效：扩展长尾音和强冲击节奏
