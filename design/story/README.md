# 背景故事方案（Pixel League Roguelike）

本目录收录三套原创背景故事方案，供后续选定主线。所有世界观、地名、角色与势力均为原创设计，不沿用任何现有 IP 的专有名词，以降低版权风险并保留玩家代入感。

## 方案一览

| 方案 | 文件 | 一句话梗概 | 核心情绪 | 叙事手法 |
| --- | --- | --- | --- | --- |
| 一 | [01-broken-ridge-watch.md](01-broken-ridge-watch.md) | 边境哨兵的游侠发现魔兽异动，层层追查到被封印的兽神祭坛。 | 守望、责任、孤独的坚守 | 线性冒险，五段边境地貌递进 |
| 二 | [02-thirteenth-chime.md](02-thirteenth-chime.md) | 每夜钟声重置小镇，只有修钟匠记得循环，必须找到停摆的源头。 | 迷惘、悬疑、时间的代价 | 循环叙事，与 roguelike 死亡重开天然吻合 |
| 三 | [03-mana-vein.md](03-mana-vein.md) | 逃离矿业公司的机械师与雇佣兵，被迫深入会唤醒怪物的魔晶矿脉。 | 反抗、利益博弈、人与资源的冲突 | 群像与阵营对立，支线可由营地商店承载 |

## 三者对比

- **故事张力**：方案一最直接，适合快速入戏；方案二最有个性，与“死亡重来”机制契合度最高；方案三阵营感最强，适合扩展多英雄与多结局。
- **制作成本**：方案一与现有“五关 + 首领”结构最贴合，文本与 UI 改动最少；方案二需要为循环设计额外的存档叙事与提示文案；方案三需要新增势力、商店与对话角色。
- **与现有英雄的契合**：现有三名英雄（凯斯特尔、维拉、奥德里克）可分别映射到三套方案的核心角色，具体建议见各文件“与玩法结合”一节。

## 通用约定（三套方案共用）

- 五段关卡对应五个区域，每关结束的传送门即为一段叙事节点。
- 首领作为每段故事的“真相片段”，击败后解锁一段回忆或线索。
- 叙事文本需同时提供英文与简体中文版本，遵循 `js/i18n.js` 的词条流程。
- 叙事不应依赖局外存档：局外碎片/强化可仅作为“线索收集”的数值化呈现。
