MODULE ANALYSIS / js/render.js

世界绘制流水线
从状态到像素

render.js 不推进战斗规则；它读取地图、单位和效果，把世界投影到低分辨率 Canvas，再放大并叠加血条/浮字。入口在 main.js:frame()，血条实现则位于 entity.js。

1 个入口renderWorld()
5 类深度对象场景物件 / 单位 / 掉落 / 弹道 / 门
2 个画布低分辨率世界层 + 全分辨率覆盖层
排序键tile-space depth: x + y

01 / MODULE CONTRACT

输入、输出与依赖边界

方向对象/接口用途
调用者main.js → renderWorld()每个动画帧在可绘制状态调用；渲染函数本身不按帧步长更新模拟。
场景输入G.map / G.ground / G.cam / G.run.portal地面、障碍、相机和可选传送门。
实体输入G.player / G.enemies / G.drops / G.projs / G.zones渲染器直接读取世界位置、动画/状态、掉落类型和颜色等字段。
显示资源ctx / sctx / view / SCALE低分辨率上下文画场景，全分辨率上下文承接放大画面后的 UI 级图层。
跨模块绘制drawSprite / drawFxGround / drawFxTop / drawHpBar / drawTexts精灵在 sprites，粒子/地面特效/浮字在 fx，血条在 entity。
输出修改 Canvas 像素，少量提交新粒子不返回场景对象；画面写入 view，再复制到主 canvas。

02 / FRAME PIPELINE

单帧绘制顺序

顺序决定遮挡和画布分辨率。只有对象队列使用深度排序；地面、区域、地面特效和顶部特效各自固定在专用阶段绘制。

01 / BASE

清屏与地面

清空 view，临时叠加镜头震动，绘制预渲染地面和区域底色。

02 / GROUND FX

地面提示

画地面特效、攻击移动射程提示与鼠标移动标记。

03 / DEPTH QUEUE

收集并排序

视野内 props 加入队列；活单位、掉落、投射物和传送门按深度排序。

04 / ACTORS

逐项绘制

按类型画物件、单位、掉落、弹道或传送门；处理树/建筑对玩家的遮挡。

05 / TOP FX

角色效果

绘制 EXTRAS，再画顶部特效、粒子、暗角和低生命红色覆盖。

06 / UPSCALE

放大与覆盖

恢复临时 camera shake；像素化放大 view，在主 Canvas 画血条和浮字。

03 / PROJECTION

坐标转换与两层 Canvas

世界 tile 坐标 (x,y,z)单位、障碍、掉落和地图效果保存的位置。
→
等距投影 + 相机isoX = (x-y) × HTW
isoY = (x+y) × HTH
toV* 再减 cam 并加视口中心。
→
view → canvas先画低分辨率 view；imageSmoothingEnabled=false 放大到主 canvas。

z 只影响垂直屏幕投影（toVY 减 z），不参与地面深度排序。对象遮挡顺序按 tile 的 x + y，与投影后的屏幕 y 有对应关系。

04 / DEPTH QUEUE

排序记录结构

props→d = prop.x + prop.y；入队前用投影边界剔除远离视口的场景物件。
Enemy / Player→d = unit.x + unit.y；仅绘制 alive 单位。
drops→d = drop.x + drop.y；受高度影响的是显示位置，不是地面深度。
projectiles→d = proj.x + proj.y + 0.5；常量偏移让弹道略晚于同位置地面对象绘制。
portal→d = portal.x + portal.y；若存在则进入同一队列。

每项的 k 是分派绘制类型，不是次级排序优先级；比较器只比较 d。重构时若要定义同深度顺序，应显式扩展比较器，不要误以为 k 已参与排序。

05 / OBJECT DRAWERS

绘制函数读取的状态

函数对象输入附加绘制/判断
drawUnit(u)Unit 子类对象阴影、精英/悬停圈、精灵帧/闪白、易伤符号、Vital 点、减速/护盾/格挡提示。
drawDrop(d)kind=gold|potion|item金币/药水/物品各自像素图；稀有物品光柱与悬停边框。
drawProj(p)追踪弹或直线技能弹小型非首领追踪弹按角度画线段；其他弹道按 size/col 画像素块。
drawPortal(o){x,y}绘制多层扩散椭圆和中心填色。
drawHpBar(u,...)从 entity.js 调用放大画面后画玩家/精英血条；普通敌人非首领才在这里补血条。
drawTexts()从 fx.js 调用主 canvas 全分辨率画伤害数字/提示，并通过 i18n 翻译。

06 / COUPLING & SIDE EFFECTS

修改时要守住的边界

状态更新不属于 render

移动、伤害、存活筛选后的删除都由 main/combat/spawner 等模块维护。render 只消费当前状态；新效果应先定义数据来源与更新者，再加绘制。

渲染不是完全纯函数

drawPortal() 以 chance() 随机调用 burst()，会向 G.parts 添加粒子。相同状态下重复绘制可能改变后续效果数量。

投影与相机属于 core

单位位置不是屏幕像素。绘制器通过 toVX/toVY、isoX/isoY 转换；逻辑层勿直接把屏幕坐标写回实体。

额外技能画法是插件点

Player.extras 的键由 EXTRAS 定义；render 遍历键并可调用 EXTRAS[k].draw()。加技能时只更新 draw，不要把技能逻辑塞进渲染模块。

屏幕覆盖分辨率不同

血条与浮字位于 upscale 后的主 canvas；普通 sprite/场景效果位于低分辨率 ctx。调整尺寸/线宽时需选对 ctx 和 SCALE。

透明状态需还原

绘制时多处修改 globalAlpha/filter/lineWidth。新分支若提前 return 或遗漏还原，可能污染后续对象绘制状态。
